Six installable skills that make Claude Code useful for actual modding work.

Modding is debugging, writing, balancing, and documenting, usually at 1 AM. These are installable skills for Claude Code, each one a repeatable habit your agent keeps forever. Install once, and every session after that your agent knows how to read a crash log, sanity-check your balance changes, or draft your patch notes.

These are real SKILL.md files, the open standard. Drop each skill folder into your Claude Code skills directory and restart. Full instructions included.

What is inside

  • mod-bug-hunter. Paste a crash log or describe the bug. Your agent walks through the likely causes in mod load order, script conflicts, and asset references instead of guessing.
  • balance-tuner. Feed it your weapon, enemy, or economy numbers. It flags outliers, suggests tuning ranges, and explains its reasoning so you stay in control.
  • dialogue-writer. NPC barks, quest dialogue, and flavor text in a consistent voice. Give it your lore notes and it keeps characters from contradicting themselves.
  • changelog-writer. Your commit messages and changed files become clean patch notes players actually read.
  • compat-checker. Before you publish, it reviews your file list against common conflict patterns: overwritten records, script collisions, load-order risks.
  • asset-organizer. Renames, sorts, and documents sprawling asset folders so your next update does not break everything.

How it works

Each skill is a folder containing a SKILL.md file. Copy the folders into ~/.claude/skills/, restart Claude Code, and the skills are live. Your agent picks them up automatically when relevant. No subscriptions, no accounts, yours forever.

Who this is for

Modders who already use Claude Code or another AI coding agent and want it to understand modding workflows instead of generic coding. Works best if you are comfortable with files and folders; no AI expertise needed beyond that.
