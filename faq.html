Frequently Asked Questions

What is an AI agent skill?

An AI agent skill is a small, installable file (called SKILL.md) that teaches your AI agent a habit. For example, a skill might say "always write a plan before starting work" or "never delete files without asking first." You install it once, and your agent follows that habit in every session after that.

Skills are different from prompts. A prompt is instructions you rewrite every time. A skill is a habit your agent keeps.

How do I install a skill?

It depends on which AI tool you use:

  • Claude Code: drop the skill folder into ~/.claude/skills/. Takes about 2 minutes.
  • ChatGPT (Business, Edu, Enterprise): upload the SKILL.md through the Skills tab in your workspace settings.
  • ChatGPT (Free, Plus, Pro): create a Custom GPT, paste the skill description into its instructions, and upload the SKILL.md as knowledge.
  • Claude (claude.ai): zip the skill folder and upload it under Settings, then Features. Requires a Pro plan or higher.
  • Grok: import the .zip or .md file as a skill.

Every Lil Nicky AI skill ships with step-by-step install guides for each platform.
